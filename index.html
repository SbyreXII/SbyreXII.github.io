XDEPhysics

Les extensions Omniverse Kit que je développe pour intégrer XDE : schémas OpenUSD dédiés, traitement runtime avec USDRT, interface de création de scènes physiques. C'est ce que j'utilise dans chaque vidéo.

Le moteur

XDE

Le moteur physique développé au CEA List. C'est lui qui calcule toutes les simulations présentées ici — pas PhysX, le moteur livré par défaut avec Omniverse.
